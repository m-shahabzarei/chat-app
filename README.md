A real-time chat application built with Next.js, Prisma, PostgreSQL, NextAuth, and Pusher. Features include live messaging, message deletion, email authentication, and responsive UI.


## نصب و راه‌اندازی

1. نصب وابستگی‌ها:

```bash
npm install
```

2. اجرای برنامه در حالت توسعه:

```bash
npm run dev
```
